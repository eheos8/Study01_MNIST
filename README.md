# 손글씨 숫자 인식 (PyTorch)

마우스로 쓴 손글씨 숫자(0~9)를 CNN 모델이 인식하는 프로젝트입니다.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `model.py` | 모델 정의 (합성곱 2층 + 완전연결 2층의 CNN) |
| `train.py` | MNIST 학습 → 가중치 `mnist_cnn.pt` 저장 |
| `app.py` | 마우스로 숫자를 쓰면 자동으로 인식하는 그림판 앱 (tkinter) |
| `mnist_cnn.pt` | 학습된 가중치 |

## 실행 환경
```bash
pip install torch torchvision pillow numpy
```
파이썬 3.9 이상을 권장합니다. `app.py`의 그림판은 파이썬에 기본 포함된 tkinter를 사용합니다.

## 사용 방법
1. 학습 (처음 실행 시 MNIST가 자동 다운로드됩니다. 몇 분 소요)
   ```bash
   python train.py
   ```
   Colab에서 이미 학습했다면 이 단계는 생략하고, 저장된 가중치를 `mnist_cnn.pt`라는 이름으로 이 폴더에 두면 됩니다.
2. 앱 실행
   ```bash
   py app.py                   # 윈도우 (맥은 python3 app.py)
   py app.py 내숫자.png         # 이미지 파일로 인식 (선택)
   ```

## 동작 방식
- 그림판에 숫자를 쓰고 마우스를 떼면 자동으로 인식하며, 결과 숫자·확신도·숫자별 확률·모델 입력(28×28)을 보여줍니다.
- 입력 이미지를 흑백으로 바꾸고, 글씨 영역만 잘라 28×28 크기 가운데에 배치합니다 (MNIST와 같은 형식).
- 모델이 0~9 각각의 확률을 계산하고, 가장 높은 숫자를 결과로 보여줍니다.
